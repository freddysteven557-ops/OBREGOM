# OBREGOM Distribuidora

Landing page estática (HTML + CSS, sin dependencias) para OBREGOM Distribuidora.

- `index.html`: página única (inicio, beneficios, catálogo con precios, nosotros, contacto).
- `styles.css`: estilos y paleta de marca (rojo `#e30613`, negro `#111111`, blanco).
- `assets/img/`: fotos de producto extraídas del catálogo.

Para verla, abre `index.html` en el navegador. Los botones de "Pedir" abren WhatsApp (316 432 0413) con un mensaje según el producto.

Para cambiar un precio, edita el texto dentro de `<p class="price">` del producto en `index.html`.
